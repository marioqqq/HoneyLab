This repository contains scripts, playbooks and docker containers for each machine / VM after fresh install. It is spread across multiple folders, depending on the purpose of the machine.

## Ansible
Navigate to [Ansible](./Ansible) for instructions on how to use Ansible to deploy and manage your infrastructure.

## Ceph
Navigate to [Ceph](./Ceph) for instructions on how to deploy and manage your Ceph cluster.

## Headscake
Navigate to [Headscale](./Manuals/Headscale.md) for instructions on how to setup and use Headscale with Tailscale.

## Misc
Navigate to [Misc](./Manuals/Misc.md) for instructions on how to use miscellaneous tools and scripts, including Kimai, Windows Activation Scripts, Windows Tool, and Adguard Home Blacklists.

## OpenWRT
Navigate to [OpenWRT](./Manuals/OpenWRT.md) for instructions on how to setup and use OpenWRT (Disable IPv6, Adguad Home, Tailscale, VLANs).

## Proxmox
Navigate to [Proxmox](./Manuals/Proxmox.md) for instructions for helper scripts and how to setup GPU passthrough for Nvidia cards.

## TrueNAS
Navigate to [TrueNAS](./TrueNAS) for instructions on how to setup custom scripts and essential containers.
